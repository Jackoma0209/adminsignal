# Lab evidence dumps

Put redacted JSON, event exports, and screenshots from a **personal** Microsoft 365 developer tenant or home Hyper-V VM here.

Do not collect Autopilot hashes, BitLocker key IDs, or `dsregcmd` output from an NHS, EEC, NORFOLK, or other employer device.

`Collect-LabDeviceEvidence.ps1` refuses common work domains unless you pass `-AllowWorkDevice`, which you should not.

After a real run, attach evidence to the matching article with `labTested` and `labScope` frontmatter. Do not set those fields without the dump.
